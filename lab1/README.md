# Лабораторная работа 1

## 1. Начальное состояние
- **Размер окна**: 520x320 пикселей
- **Минимальный размер**: 240x200 пикселей
- **Компоненты**:
  - **Надпись** - текстовое поле 160x40 пикселей
  - **Кнопка 1** - кнопка 160x40 пикселей для переключения текста
  - **Кнопка 2** - кнопка 160x40 пикселей для загрузки изображений

## 2. Кнопка 1: Переключение текста
- Циклически меняет содержимое надписи
- **Цикл**: "Надпись" -> "Привет" -> "Надпись" -> ...
- При каждом нажатии текст в надписи обновляется
- Работает независимо от состояния загруженного изображения

## 3. Кнопка 2: Загрузка изображений
- Циклически загружает изображения из папки `images`
- **Цикл**: начальное состояние -> изображение 1 -> изображение 2 -> изображение 3 -> начальное состояние -> ...
- При загрузке изображения:
  - Окно автоматически изменяет размер в соответствии с размерами изображения
  - Изображение устанавливается как фон окна

## 4. Горизонтальный и вертикальный макеты

### Горизонтальный макет (ширина окна >= 440 пикселей):
Надпись расположена в центре верхней части. Кнопки расположены в одном ряду с расстояниями (при ширине 440):
- 40 пикселей слева от левой части окна до Кнопки 1, между кнопками и справа от Кнопки 2 до правой кромки окна
- 160 пикселей размер кнопок

### Вертикальный макет (240 <= ширина окна < 440 пикселей):
Все элементы расположены вертикально по центру. Каждый элемент имеет одинаковый отступ слева и справа (40 пикселей). Расстояние между элементами: 40 пикселей.

## 5. Обработка больших изображений

- Если изображение превышает размер экрана, оно автоматически масштабируется
- Пропорции изображения сохраняются при масштабировании
- Размер окна адаптируется под масштабированное изображение, но не превышает размеры монитора
