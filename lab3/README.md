# Лабораторная работа №3

## Основы проектирования графического интерфейса компьютерных систем

### Начальное состояние

Размер окна: 900x600 пикселей. Компоненты:

1. **Меню Файл** с двумя пунктами: *Set connection* и *Close connection*
2. **Выпадающий список** для выбора колонки системной таблицы `sqlite_master` (name, type, tbl_name, sql)
3. **Три функциональные кнопки**: bt1 (Запрос 1), bt2 (Запрос 2, bt3 (Запрос 3)
4. **QTabWidget** с пятью вкладками (Tab1-Tab5), содержащими таблицы для отображения результатов SQL-запросов

До установки соединения с базой данных все элементы управления (кнопки и выпадающий список) заблокированы.

### Функции меню

**Пункт Set connection:**
1. Открывает диалоговое окно для выбора файла базы данных
2. Устанавливает соединение с выбранной БД
3. После успешного подключения автоматически выполняет запрос `SELECT * FROM sqlite_master` и заполняет таблицу на Tab1
4. Разблокирует все элементы управления

**Пункт Close connection:**
1. Закрывает соединение с базой данных
2. Очищает все пять таблиц на вкладках
3. Блокирует элементы управления

### Функции кнопок и выпадающего списка

**Кнопка bt1:**
1. Выполняет запрос `SELECT name FROM sqlite_master`
2. Результат выводится в таблицу на Tab2
3. Автоматически переключает пользователя на Tab2

**Выпадающий список:**
1. Содержит названия колонок системной таблицы: `name`, `type`, `tbl_name`, `sql`
2. При изменении выбора формируется динамический запрос вида `SELECT {выбранная_колонка} FROM sqlite_master`
3. Результат выводится в таблицу на Tab3
4. Автоматически переключает пользователя на Tab3

**Кнопка bt2:**
1. Выполняет запрос `SELECT name, type FROM sqlite_master WHERE type='table'`
2. Результат выводится в таблицу на Tab4
3. Автоматически переключает пользователя на Tab4

**Кнопка bt3:**
1. Выполняет запрос `SELECT name, sql FROM sqlite_master WHERE type='table' AND sql IS NOT NULL`
2. Результат выводится в таблицу на Tab5
3. Автоматически переключает пользователя на Tab5
